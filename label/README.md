# ESP knob label (MS-20 iC)

130 x 30 mm sticker for the five ESP knobs. `python3 label.py esp_label.pdf` (needs reportlab).
Dimensions are in MEAS at the top of label.py. Font: Barlow Semi Condensed, SIL Open Font License (https://github.com/jpt/barlow).

Variants: `STYLE=italic INK='#c4c3be' ARPC='#e8542a' python3 label.py esp_label.pdf` (current: italic + orange arp).
sticker.py: 100 x 30 mm give-away sticker. Fonts: Barlow Semi Condensed, Archivo Black, Big Shoulders Display (all SIL OFL).
